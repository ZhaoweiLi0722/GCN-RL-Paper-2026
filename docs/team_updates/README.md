# Team Research Updates

This directory contains English-language updates intended for the project team.
Each reporting cycle may include two documents:

- a concise weekly update for meetings and quick review;
- a detailed research update with methods, results, limitations, provenance,
  and progression decisions.

Personal notes and Chinese-language working logs remain under the ignored local
directory `docs/local_progress_reports/`.

concise updates. Detailed updates should link each quantitative claim to a
committed result note or an archived artifact with a recorded hash.
