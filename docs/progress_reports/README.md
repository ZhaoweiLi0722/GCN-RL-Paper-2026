# Weekly Progress Reports

This directory records weekly, evidence-traceable progress for the GCN-RL
project. Reports are intended for research meetings, collaboration handoffs,
and later manuscript revision.

## Reporting Cadence

- Prepare one report before the weekly collaborator meeting.
- Name reports `YYYY-MM-DD-short-topic.md`.
- Separate verified results from experiments that are still running.
- Trace quantitative claims to committed result notes, aggregate files, or
  archived artifacts with hashes.
- Record negative and inconclusive findings; do not report only favorable runs.
- Keep raw checkpoints, large result archives, and restricted data outside the
  public repository. Record their provenance and SHA256 instead.

## Standard Sections

1. One-sentence status.
2. Work completed since the previous report.
3. Verified experimental results.
4. Experiments in progress.
5. Claims supported and not yet supported.
6. Risks, blockers, and data-quality concerns.
7. Decisions needed from collaborators.
8. Next-week priorities and progression gates.
